## 关键决策

### 1. 删掉 `src/main_server.cpp`

旧实现完整保存在 `f1a5d6c`，用 `git show f1a5d6c:src/main_server.cpp` 可取回。
M0.5 会在新结构上重写它，并逐个修掉其中的缺陷——保留一份"待删的死代码"
只会让新读者困惑。

### 2. 警告即错误（CI 中开启 `-Werror`）

本地默认关（方便边写边试），CI 强制开。包括 `-Wconversion` / `-Wsign-conversion`，
因为 `ssize_t` ↔ `size_t` ↔ `int` 之间的隐式转换在网络代码里是真实的 bug 来源。

### 3. `.gitattributes` 强制 LF

项目在 Linux 上编译，脚本以 `#!/usr/bin/env bash` 开头。Windows 的 CRLF 会让
WSL 报 `$'\r': command not found`。在版本层面统一，是唯一可靠的办法。

### 4. 容器两阶段构建

builder 阶段装工具链、编译、跑测试；runtime 阶段只拷二进制。镜像从 ~800MB
降到 ~80MB，且不以 root 运行。

### 5. 版本号单一来源

`project(VERSION 0.1.0)` 通过编译定义注入源码，不在 `.cpp` 里再写一遍。
